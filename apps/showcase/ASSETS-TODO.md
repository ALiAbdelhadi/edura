# ASSETS-TODO — what the showcase needs from a human

Everything the site can generate for itself (screenshots, flow videos, SVG diagrams,
device frames) is produced by the Phase 2 pipeline from a seeded local app. This file
lists only what that pipeline **cannot** produce, split into things that block a page and
things the site is designed to live without.

Last updated 2026-08-02, after the flow videos landed.

---

## 0. Video — DONE (ffmpeg installed 2026-08-02)

`ffmpeg 8.1.2` (Homebrew, with `libx264` and `libvpx-vp9`) replaced Playwright's
bundled build, which ships **VP8 and PNG encoders only** and cannot produce mp4.

Six clips recorded and encoded (`bun run flows` → `bun run encode:flows`):

| Flow | Locales | Length | mp4 | webm (VP9) |
|---|---|---|---|---|
| `counter-checkin` | ar · en | 5.2s / 6.8s | 34 / 44 KB | 54 / 57 KB |
| `teacher-register` | ar · en | 3.2s | 58 / 78 KB | 46 / 53 KB |
| `student-subjects` | ar · en | 2.8s / 3.2s | 44 / 60 KB | 36 / 43 KB |

**0.6 MB of video in total**, all under the 8s budget, all with no audio stream
at all (`-an`), each with an AVIF + WebP poster.

Still to record when the pages need them: the parent-pays flow and the offline
attendance outbox. Neither is a tooling problem — the payment one writes
append-only money rows so it is a deliberate one-time hand-run, and the offline
one needs a scripted network cut.

**Frame sequences for scroll-scrubbed scenes are not built yet.** They do not
need ffmpeg (Playwright steps + screenshots, `sharp` encodes the WebP sequence);
they are simply waiting for Phase 4 to say which scene wants one.

## 3. Generated by the pipeline — no human input needed

Recorded here so the split is unambiguous.

- 2× screenshots of every key screen, per role, both locales, fixed viewport →
  `public/shots/<role>/`
- Recorded flow videos (Playwright → ffmpeg h264 + vp9, ≤8s, muted) + extracted poster
  frames
- Scroll-scrubbed webp frame sequences for the Apple-style scenes
- SVG browser / phone device frames, drawn in the design system
- Original SVG diagrams: settlement split, immutable ledger, minor-safety shield, center
  data isolation, offline outbox, door check-in stages
- OG / social preview images, composed from the above

**Every screenshot comes from a seeded demo center with fictional Arabic names**
(`is_demo`, dev only, zero money rows — approved 2026-08-02). Any figure visible in a
money screenshot comes from a flow run manually in the preview, because the seed is
forbidden from writing to the ledger.
