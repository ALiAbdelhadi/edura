# مراجعة ما قبل الإطلاق — امشِ على دور واحد بالكامل

انسخ القسم الخاص بدورك في جلسة جديدة. **جلسة واحدة = دور واحد.**

---

## القواعد المشتركة (تنطبق على كل الأدوار)

**١. بلّغ، لا تُصلح.** خمس جلسات تعدّل نفس الريبو = تعارضات. اكتب كل عطل في تقرير
نهائي: الشاشة، الخطوة، المتوقَّع، الحاصل، ورسالة الكونسول. **لا تعدّل كودًا** إلا لو
العطل بيمنعك تكمّل، وساعتها قول إنك عدّلت وإيه بالظبط. **لا `commit` ولا `push`** —
ده مكتوب في `CLAUDE.md` كقاعدة ملزِمة.

**٢. hostname خاص بيك — مش بورت.** الكوكي في المتصفح متعلّقة بالـ**hostname**
مش بالبورت، فكل الجلسات على `localhost` بتتشارك نفس `edura.session_token`
وبتطرد بعض. المتصفح بيحوّل أي `*.localhost` لـ127.0.0.1 تلقائيًا، والكوكي وقتها
بتتعزل. **و`NEXTAUTH_URL` لازم يطابق العنوان بالظبط** وإلا better-auth يرفض.

| الدور | العنوان | البورت |
|---|---|---|
| طالب | `http://student.localhost:3051` | 3051 |
| مدرّس | `http://teacher.localhost:3052` | 3052 |
| ولي أمر | `http://parent.localhost:3053` | 3053 |
| سنتر | `http://center.localhost:3054` | 3054 |
| سوبر أدمن | `http://admin.localhost:3055` | 3055 (تطبيق `apps/superadmin`) |

```json
{ "name": "walk-<الدور>", "runtimeExecutable": "sh",
  "runtimeArgs": ["-c", "NEXTAUTH_URL=http://<الدور>.localhost:<PORT> exec bun run --cwd apps/www next dev -p <PORT>"],
  "port": <PORT>,
  "url": "http://<الدور>.localhost:<PORT>" }
```

**لو لقيت نفسك مطرودًا فجأة ومتكرر — ده مش باگ في المنتج، ده جلسة زميل كتبت
الكوكي فوقك. اتأكد إنك على الـhostname بتاعك مش على `localhost` عاري.**

**٣. قاعدة البيانات مشتركة (dev).** كلكم على نفس القاعدة. القراءة والتنقل آمنة.
**الكتابة في الفلوس (دفع، محفظة، تسوية) اعملها بحساب واحد بس ووسّمها** باسم واضح
عشان نعرف نشيلها. لو لقيت بيانات بتتغير من تحت إيدك — ده زميل شغال، مش باگ.

**٤. الأولوية بالخطورة مش بترتيب التابات.** ابدأ بالدخول، بعده الفلوس، بعده الحضور،
وبعدين الباقي. لو الوقت خلص، يبقى خلصت الأهم.

**٥. كل الحسابات باسوردها `Passw0rd!`**

بالترتيب: الدخول والخروج ← البطاقة (`/dashboard/student/id`: نسخ الرقم، حفظ كصورة،
طباعة، وافحص الـPNG بصريًا) ← الإعدادات (البطاقة المصغّرة، الأجهزة والجلسات، حقوق

الجدول ← الحضور ← الدرجات ← المواد ← الرسائل ← رمز العائلة ← الإشعارات.

**ركّز على:** زياد لازم **ما يقدرش** يطبع بطاقة (كوده مؤقت) — لو قدر، ده عطل.
وجرّب البطاقة في الدارك مود وعلى مقاس موبايل.

## ولي الأمر — بورت 3053

ابحث عن حساب: `SELECT email FROM users WHERE role='parent' AND is_demo LIMIT 3;`
(مبدئيًا حسابات `parentpay-demo-*`)

الدخول ← أبنائي والربط (اقبل/ارفض/الغِ) ← **بطاقة الابن** (`/dashboard/parent/children/<id>/id`
— لازم تشتغل للمعتمد وترفض غير المعتمد) ← محفظة ولي الأمر (شحن، ادفع لحصة ابنك) ←
المصاريف والإيصالات ← التقدّم والحضور ← الرقابة على المراسلات ← الإشعارات.

**ركّز على:** الدفع لابن **معتمد** لازم يعدّي، ولابن **غير معتمد** لازم يترفض.
وبعد الدفع، الإيصال لازم يطلع صح بالعربي.

## التقرير النهائي

اكتبه هكذا، مرتّبًا بالخطورة:

```
الدور: ___    البورت: ___
يمنع الإطلاق:  (فلوس غلط · تسريب بيانات · شاشة واقعة · دخول مكسور)
خطير:          (وظيفة ناقصة، رسالة خطأ غامضة)
تجميلي:        (مسافات، ترجمة، أيقونة)
لم أستطع اختباره: ___ والسبب
```

**لو لقيت أي حاجة في الخانة الأولى — قول لعلي فورًا، ما تستناش لآخر التقرير.**
